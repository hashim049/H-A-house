# H-A House

1. Replace your root `index.html` with the included file.
2. Change `WHATSAPP_NUMBER` in index.html to your business WhatsApp number (country code, no + or spaces).
3. Run `supabase.sql` in Supabase SQL Editor.
4. Keep admin/config.js, admin/login.html and admin/dashboard.html.
5. Open /admin/login.html to see orders.

This version is an MVP: WhatsApp orders are saved in Supabase before WhatsApp opens. Payment gateway and affiliate tracking can be added next.
